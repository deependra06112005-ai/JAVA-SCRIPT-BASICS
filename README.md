#Manu Hardware -Paint Shop

Paint Shop Management System For my retail business..in jhansi uttar pradesh


##Live Link 
https://manuhardware-paintshop-app.vercel.app

#Features
-View All Paints and hardware items
-Add new paint and all hardware items
-Edit Quantity / Pc 
-Delete Paint/items
-Low Stock Alerts

#Tech Stack
-Frontend: React.js
-Backend: Node.js+Express js
-Database: MongoDB Atlas
-Deployed:Vercel + Render
